# The Lembongan Traveller - CRM Travel

## Node Version

```bash
  node v22.14.0
```

## NPM Version

```bash
  node 10.9.2
```

## Use NVM - Change Node Version

```bash
  nvm use v20.5.1
```

## Installation

```bash
  npm install
```

Building Development

```bash
  npm run build:development
```

Building Staging

```bash
  npm run build:staging
```

Building Production

```bash
  npm run build:production
```
